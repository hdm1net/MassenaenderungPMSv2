# Massendatenänderung OSPlus

## 📋 Übersicht

Tool zur Massendatenänderung für die Gesamtbank-Lösung OSPlus der Finanz Informatik.
Das Tool nutzt die PMS-Schnittstelle zum Aufruf der DynS-Webservices.

Das eigentliche Tool ist ein Kommandozeilenwerkzeug zur Durchführung der eigentlichen Massendatenänderung. Darüber hinaus existiert eine grafische Oberfläche (Gui). Mit dessen Hilfe können Steuerungsdateien (XML) für das Kommandozeilentool erstellt und auch die eigentliche Massendatenänderung gestartet werden.
